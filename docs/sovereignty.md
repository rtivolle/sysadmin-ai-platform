# Sovereignty / blocked-egress operation

How to install and run the sysadmin AI platform with public egress blocked
(PR-D3). The platform is on-premises and loopback-bound by default: only Traefik
listens on all interfaces, and every model/LLM endpoint defaults to a local
proxy. This page documents the remaining external surfaces, the exact switch to
disable or mirror each one, and the tooling that verifies the result.

> **Measurement status:** a blocked-egress **full-suite run has not been
> measured on this host**. The static census (below) is green; the runtime
> egress check reports **unmeasurable** on this host because no platform
> services were running and unprivileged user namespaces are disabled. See
> [§6 Acceptance procedure](#6-acceptance-procedure).

## 1. The census tool

`backend/tests/qualification/egress_audit.py` classifies every outbound
destination and telemetry/cloud fallback in the platform's own code and config.

```bash
# Static census (default): scan + classify every destination, exit 0 iff clean.
backend/.venv/bin/python3 backend/tests/qualification/egress_audit.py

# Runtime check: sample ss -tnp for the live platform PIDs' non-loopback
# connections, falling back to an `unshare -rn` import smoke.
backend/.venv/bin/python3 backend/tests/qualification/egress_audit.py --runtime --seconds 5
```

Exit codes: `0` = clean/classified; `1` = an unclassified external destination
appeared in runtime code (static) or a non-loopback connection was attributed
to a platform PID (runtime); `2` = harness error / unmeasurable.

The allowlist (`backend/tests/qualification/egress_allowlist.json`) is the
single source of truth for the classification. Adding or changing an outbound
destination without updating it makes the census exit `1`.

## 3. Exact environment settings for blocked-egress operation

Names below are verified against the platform code and the dependency-documented
interfaces. Set them in the service environment (`platform.sh` / systemd drop-in
/ deployment profile) before starting under a blocked-egress firewall.

| Variable | Value | Why | Set by platform? |
|---|---|---|---|
| `litellm_settings.telemetry` | `false` (config.yaml) | LiteLLM anonymous telemetry | **yes** (`backend/config/litellm/config.yaml`) |
| `DSH_TELEMETRY_DISABLED` | `1` | DeepSeek Harness telemetry | **yes** (gateway `instance-manager.js`) |
| `SYSADMIN_LITELLM_URL` | `http://127.0.0.1:4000/v1` | Harness LLM endpoint → local proxy | **yes** (default) |
| `VLLM_NO_USAGE_STATS` | `1` (or `DO_NOT_TRACK=1`) | vLLM usage-stats collector | **no** — export it for the vLLM child |
| `HF_HUB_DISABLE_TELEMETRY` | `1` | `huggingface_hub` usage events | **no** — export it |
| `HF_ENDPOINT` | `https://<internal-mirror>` | model download from a mirror | **no** — export it |
| `HF_HUB_OFFLINE` | `1` (air-gapped) | never touch the Hub network | **no** — export it |
| `HF_HOME` | `<local cache dir>` | model cache location | optional |
| `PIP_INDEX_URL` | `https://<internal-pypi-mirror>/simple` | pip installs from a mirror | **no** — set at install |
| `PIP_NO_INDEX` | `1` (fully offline) | forbid PyPI lookups | **no** — set at install |
| `NO_UPDATE_NOTIFIER` | `1` | disable npm update-notifier phone-home | **no** — set at install |
| npmrc `audit=false fund=false` | — | disable npm audit/fund requests | **no** — set at install |

The three "**no**" runtime entries (vLLM usage stats, HF Hub telemetry, HF Hub
mirror) are the residual gaps to close for a hardened blocked-egress build;
until then they must be exported by the operator.

## 4. Controlled artifact import (mirror procedure)

Blocking egress does not remove the need to *import* artifacts once. Treat
imports as a controlled, logged, single-direction process on a separate
build/transfer machine, never on the runtime host.

1. **Python packages** — build wheels on the mirror host, serve a devpi/
   Artifactory index, then `PIP_INDEX_URL=<mirror> pip install …` or vendor
   wheels and `pip install --no-index --find-links <dir>`.
2. **Node / harness packages** — point npm at an internal registry
   (`npm config set registry <mirror>`), pre-stage `@deepseek-ai/dsh` and the
   `@deepseek-ai/*` bundles, then `DSH_BIN=<mirrored launcher>`.
3. **Static binaries** (Traefik, VictoriaLogs, SeaweedFS) — download the pinned
   versions from `install.sh` once, hash them, and place them in
   `backend/bin/` (the installer skips already-present binaries).
4. **Valkey** — download the pinned `valkey-7.2.14-jammy-<arch>.tar.gz` and
   its `.sha256` from `download.valkey.io` once, verify the hash, and place
   the binaries in `backend/bin/` (the installer skips already-present
   binaries); alternatively install `valkey-server` from the distro mirror.
5. **Models** — download the pinned `org/repo@revision` from the internal
   HuggingFace mirror (`HF_ENDPOINT`), into the local `MODELS_DIR`, once, on a
   transfer host; the runtime host then runs with `HF_HUB_OFFLINE=1`.

Record every imported artifact's version + SHA-256 in the release manifest
(PR-D4) so the runtime host's inputs are reproducible and auditable.

## 5. Local DNS / NTP / PKI

Blocked egress also removes the ability to reach public infrastructure that the
host itself may assume:

- **DNS** — run a local resolver (`systemd-resolved`, `dnsmasq`) and pin
  `/etc/resolv.conf` to it; the platform services never resolve public names at
  runtime (they use `127.0.0.1`), so this is about the host's own tooling.
- **NTP** — serve time from a local stratum (chrony on the LAN) so audit
  timestamps (`YYYY-MM-DDTHH:MM:SSZ`, see the audit schema) stay trustworthy.
- **PKI** — host a private CA for the Traefik TLS front door and the future
  inter-machine TLS (PR-H2); every service verifies upstream certificates
  against that CA, never a public trust store.

## 6. Firewall (egress-deny for the platform user — example, NOT applied)

The multi-host split already ships default-deny output chains in
`backend/config/firewall/{web,inference,data}.nft`. For a **single host**
(`ROLE=all`) that must reach nothing public, run the platform services under a
dedicated service group and deny its outbound egress while allowing loopback
and established/related — the same shape the repo already uses:

```nft
#!/usr/sbin/nft -f
# Single-host egress-deny for the platform service group (NOT applied by the
# installer). Review the interface, GID and any NTP/DNS/management exceptions,
# then load explicitly:  nft -f backend/config/firewall/egress-deny.nft

define LAN_IFACE   = "eth0"
define PLATFORM_GID = 1001   # group the services run under (site-specific)

table inet sysadmin {
  chain output {
    type filter hook output priority 0; policy drop;

    ct state established,related accept
    oif lo accept

    # Exceptions the platform needs if DNS/NTP are not fully local:
    #   udp dport 53  ip daddr <local-resolver> accept
    #   udp dport 123 ip daddr <local-ntp> accept
  }
}
```

The `policy drop` output chain is what makes a misconfigured client fail closed
rather than silently reach the internet. Apply it as a separate, reviewed step —
never as part of `install.sh`.

## 7. Acceptance procedure

1. Install the artifacts through the controlled import process (§4); verify
   every hash against the manifest.
2. Apply the firewall ruleset (§6) and the environment table (§3).
3. Run the static census and confirm exit `0`:
   `backend/.venv/bin/python3 backend/tests/qualification/egress_audit.py`.
4. Start the stack, then run the runtime check and confirm **no** non-loopback
   connection is attributed to a platform PID:
   `backend/.venv/bin/python3 backend/tests/qualification/egress_audit.py --runtime --seconds 10`.
5. Capture firewall evidence: `nft list ruleset` (or `iptables-save`) plus a
   `ss -tnp` snapshot taken during the run, and attach both to the acceptance
   report.
6. Run the full verification suite (`make test`, `make test-live`,
   `make harness-test`) with egress blocked and record the result in
   `docs/status/TEST_READY.md`.
7. For each runtime-external destination still unset in code (§2), either set
   the switch in `platform.sh`/`vllm_server.py` and re-run the census, or
   record it as an operator-set control in the acceptance report.
